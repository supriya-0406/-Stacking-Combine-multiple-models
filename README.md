# 🧠 Customer Purchase Prediction using Stacking Ensemble

## 📌 Overview

This project combines multiple machine learning models using stacking ensemble learning to improve prediction performance.

---

## 🎯 Objective

Predict whether a customer will purchase a product.

---

## 🧠 Models Used

* Random Forest
* Support Vector Machine (SVM)
* Logistic Regression (Meta Model)

---

## 📊 Dataset

Customer features:

* Age
* Income
* Spending Score

Target:

* Purchased (0 or 1)

---

## ⚙️ Technologies

* Python
* Pandas
* Scikit-learn

---

## 🚀 How to Run

pip install -r requirements.txt
python main.py

---

## 📈 Output

* Customer purchase predictions
* Model accuracy
